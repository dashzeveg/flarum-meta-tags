# Meta Tags

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/dashzeveg/flarum-meta-tags.svg)](https://packagist.org/packages/dashzeveg/flarum-meta-tags) [![Total Downloads](https://img.shields.io/packagist/dt/dashzeveg/flarum-meta-tags.svg)](https://packagist.org/packages/dashzeveg/flarum-meta-tags)

A [Flarum](https://flarum.org) extension. Automatically adds Open Graph, Twitter Card, and meta description tags to your Flarum forum for better SEO and social media sharing.

## Installation

Install with composer:

```sh
composer require dashzeveg/flarum-meta-tags:"*"
```

## Updating

```sh
composer update dashzeveg/flarum-meta-tags:"*"
php flarum migrate
php flarum cache:clear
```
